### AI-Powered Resume Analyzer

ResumeScope is a full-stack AI-powered web application that analyzes resumes, calculates ATS scores, compares resumes against job descriptions, generates personalized career roadmaps, and creates interview questions using Groq AI.

🌐 **Live Demo:** https://resume-scope-lac.vercel.app

⚙️ **Backend API:** https://resumescope-backend.onrender.com
